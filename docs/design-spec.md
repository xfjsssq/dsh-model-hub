# dsh-model-hub 设计规格（Lead 冻结版）

版本：v1 · 2026-10-23 · 若需变更请先通知 Lead

## 1. 目标与不变量

**目标**：把 DSH 聊天界面的模型选择从"一长串扁平列表"改成 **双栏（左：提供商 / 右：该提供商的模型）**，支持模型名搜索；鼠标悬停模型行时浮出**能力详情卡**，可在卡上直接改上下文档位、输出档位、视觉开关、思考档位，且**改动真实生效**。

**不变量（必须成立，否则不算完成）**

1. **真选中**：在选择器里点选模型 = 调 `modelDirectories.directoryFor(sessionId).select(...)`，与内置 `/model` 弹窗是同一份会话级目录 → composer 上显示的名字、后续请求实际使用的模型都会变。
2. **真生效**：能力修改（上下文/输出/视觉/思考档位）必须真正改变运行时模型信息与请求参数，**不能只是本地的视觉状态**。每次写入后必须能读到回执（`/model-hub/api/model` 返回 `effective`），并能在宿主侧复现。
3. **可回滚**：`enabled: false` 时内置模型选择器完全恢复原样，无残留 CSS / DOM。
4. **不引入白屏风险**：客户端 bundle 任何异常都不能让聊天界面挂掉（顶层 try/catch + 出错时安静的降级：不渲染我们的 UI，让内置控件继续工作）。
5. **零外部依赖**：只用 `react` / `react-dom`。
6. **主题跟随**：只使用 `--dsw-*` 变量与 `color-scheme`，明暗主题都要好看。

## 2. 交互流程

```
composer 模型位（槽位 conversation.input.model）
        │ 点击
        ▼
┌──────────────────────── 弹窗（portal → body）────────────────────────┐
│  ┌──────────────┐  ┌───────────────────────────────────────────────┐ │
│  │ 提供商 (可拖动)│  │ 搜索框  [🔍 输入模型名…]              (×)      │ │
│  │ ─────────────│  ├───────────────────────────────────────────────┤ │
│  │ ▍jia      12│  │ m-flash-1017   [视觉][1000K][高]  │ │◀ 悬停 120ms
│  │  yi       8│  │ m-qwen-flash            [1000K]            │ │   ┌───────────────┐
│  │  bing    9│  │ …                                             │ │   │ 上下文 128K·256K·1000K │
│  │  …           │  │                                               │ │   │ 输出   128K·256K       │
│  └──────────────┘  └───────────────────────────────────────────────┘ │   │ 视觉   [ ●——]          │
│                                                                      │   │ 思考   off·low·mid·high│
└──────────────────────────────────────────────────────────────────────┘   └───────────────┘
```

- 打开动画：遮罩 opacity 0→1（140ms）；面板 `scale(.985) translateY(6px)` → `scale(1) translateY(0)` + opacity（180ms）。
- 关闭：反向 120ms，Esc / 点击遮罩 / 再次点击触发器。
- 切换提供商：右栏内容做 6px 横向位移动画 + opacity 交叉淡入（140ms），滚动位置归零。
- 搜索：输入即过滤（无需回车），右侧列表 80ms 内更新；高亮匹配字符；无结果显示"没有匹配的模型"。

## 3. 尺寸与层次（token 化，全部走 --dsw 变量 + 少量自有 CSS 变量）

| 项 | 值 |
|---|---|
| 弹窗宽 | `min(920px, calc(100vw - 48px))` |
| 弹窗高 | `min(640px, calc(100vh - 96px))` |
| 圆角 | 20px（内部卡片 14px，chip 999px） |
| 内边距 | 面板 16px；左栏行 10px 12px；右栏行 10px 14px |
| 左栏宽 | 236px（固定，右侧 1px 分隔线） |
| 层级 | 遮罩 z-index 1200；弹窗 1201；悬浮卡 1202（在弹窗内部，用绝对定位而非新 portal） |
| 字号 | 标题 15/600；行 14/400（选中 14/500）；徽标 11/500；说明 12/400 |
| 阴影 | 弹窗 `var(--dsw-shadow-lv3)`；悬浮卡 `var(--dsw-shadow-lv2, var(--dsw-shadow-lv3))` |
| 背景 | 弹窗 `var(--dsw-alias-bg-layer-2)`；悬浮卡 `var(--dsw-alias-bg-layer-3, ...)`；遮罩 `var(--dsw-alias-bg-mask-1)` + `backdrop-filter: var(--dsw-mask-blur)` |

颜色只用语义别名：`--dsw-alias-label-primary/secondary/tertiary`、`--dsw-alias-interactive-bg-hover/active`、`--dsw-alias-brand-primary`（强调/选中）、`--dsw-alias-border-*`。**禁止硬编码色值**（唯一例外：品牌微光的低透明叠加，需同时给明暗两套）。

## 4. 左栏：提供商

- 行内容：`名称` + 右侧 `模型数`（12px，tertiary 色）。
- 选中态：左侧 3px `--dsw-alias-brand-primary` 圆角竖条 + 背景 `interactive-bg-hover`，文字 primary/500。
- 悬停态：背景 `interactive-bg-hover`，140ms 过渡。
- 拖动排序：按住行拖到目标位置显示插入指示线（2px brand 色）；松手即持久化 `POST /model-hub/api/prefs {order}`。拖动中光标 `grabbing`，被拖行 0.98 缩放 + 阴影。
- 置顶：右键或行尾小图钉图标（悬停才显示）；置顶的提供商固定在最前，与 order 一起持久化。
- 默认排序：DeepSeek 官方类（deepseek / deepseek-account）第一、第二，其余按 `order` 里的顺序，未记录的按目录原序。

## 5. 右栏：模型

- 行内容：`模型名`（超长省略号 + title 提示）；行尾徽标组（最多 3 个）：
  - 视觉：`👁 视觉`（或一个内联 SVG 的眼睛），仅当 vision=true。
  - 上下文：`1000K` / `256K` / `128K`（由 contextWindow 折算，非整档显示实际值）。
  - 思考：`思考·高`（仅当模型有 efforts）。
- 当前会话已选中的模型：行首一个 brand 色对勾；行背景轻微 brand 透明叠加（≤6%）。
- 悬停：`interactive-bg-hover`；键盘高亮同款底色。
- 点击：调 `select`（带 in-flight 状态：行尾换成 14px 转圈图标，期间禁用重复点击）；失败则弹一条内联错误条（红/黄语义色），**不要用 alert**。

## 6. 悬浮能力卡

- 触发：行 `mouseenter` 后 **120ms** 才出现；`mouseleave` 后 140ms 消失（进入卡片则取消消失）。
- 定位：贴在被悬停行的右侧（空间不足则翻到左侧），垂直与被悬停行顶部对齐；始终保持在视口内（上下 12px 边距）。
- 出现动画：opacity + `translateX(-6px → 0)`，160ms。
- 内容：
  1. 标题行：模型名 + 提供商名（12px tertiary）。
  2. **上下文** 分段控件：`128K` `256K` `1000K`（值 131072 / 262144 / 1000000）。若模型当前值不在这三档内，则额外显示一个 current 段位（例如 `1024K`）并高亮。
  3. **输出** 分段控件：`128K` `256K`（131072 / 262144），同上处理非标值。
  4. **视觉** 开关：`role="switch"` 的可访问开关，36×20 轨道，圆点 16px，180ms 位移过渡。
  5. **思考档位**：off / low / medium / high 分段控件；模型未公布 efforts 时整行隐藏，并显示一行 12px 说明"该模型未公布思考档位"。
  6. 底部 11px 提示："改动立即生效并保存到模型配置"。
- 分段控件：轨道 `bg-layer-3`，选中块用 brand 色 12% 透明底 + brand 文字，切换时选中块有 160ms 的位移/淡入。
- 写入：点击即乐观更新（立刻高亮）+ `POST /model-hub/api/model`；成功后用返回的 `effective` 校准；失败回滚到旧值并在卡片底部显示错误（红点 + 文案，4s 后淡出）。
- 正在写入时该控件显示 12px 转圈，禁用重复点击（允许改不同字段）。

## 7. 键盘与无障碍

- 打开：焦点落到搜索框。
- `↑/↓`：在模型行间移动高亮（此时焦点保留在搜索框，与内置行为一致），并同步右栏滚动。
- `←/→`：切换上/下一个提供商（在搜索框内时仍用于移动光标 → 仅当搜索框为空时生效）。
- `Enter`：选中高亮模型并关闭（若正在改能力则不关闭）。
- `Esc`：先关悬浮卡，再关弹窗，焦点回到触发器。
- `Tab`：在搜索框 → 模型列表 → 悬浮卡控件之间循环。
- 所有可点元素：`role`/`aria-*` 齐全，`:focus-visible` 用 2px brand 外环；鼠标 hover 与键盘高亮视觉一致但不显示焦点环（与内置约定一致）。
- `prefers-reduced-motion: reduce` 时所有过渡降为 0ms（保留 opacity 的 1ms 以防闪烁）。

## 8. 状态与数据

- `GET /model-hub/api/catalog`：providers + models + 元数据 + 是否有凭证。
- `GET/POST /model-hub/api/prefs`：order / pinned / overrides。
- `POST /model-hub/api/model`：能力写入。
- 目录刷新：监听 host 的 `llm/adapters-updated`（客户端侧若不可得，则每次打开弹窗都重新拉一次 catalog；写入成功后也重拉）。
- 选中态：来自 `modelDirectories` 的快照（会话级），不要自己维护"当前模型"。

## 9. 完成定义（Definition of Done）

1. 点击 composer 模型位 → 打开新弹窗（不是内置列表）。
2. 左栏列出全部 12 个提供商，可拖动排序，重启后顺序保持。
3. 右栏只显示所选提供商的模型；搜索能跨当前提供商的模型名/ID 模糊匹配（打开时搜索框为空、显示全部）。
4. 悬停模型 → 详情卡出现，可改 4 类能力，写入后 `prefs.json` 与运行时模型信息同步变化。
5. 点选模型 → composer 名称变化 + 后续请求使用该模型。
6. 刷新页面/重启 DSH 后一切保持；`enabled: false` 后完全恢复内置 UI。
7. 明暗两套主题截图无破版；无控制台报错。

## 10. 修订 v1.1（2026-10-23，Lead 裁决，**覆盖第 5 节与第 9 节中关于搜索范围的表述**）

**搜索范围改为全局。** 原表述「搜索只在当前提供商的模型内匹配」作废。

- **查询为空**：行为不变 —— 左栏选中的提供商 → 右栏显示它的全部模型。
- **查询非空**：忽略左栏选中态，在**全部提供商**（含折叠区）内按 name/id 模糊匹配；右栏改为**按提供商分组的平铺结果**：每组一个 12px 小标题（提供商名 + 命中数），组内沿用 `rankByName`，只显示有命中的组，分组顺序沿用 `orderProviderIds`。
- 结果行的徽标（视觉/上下文/思考）、选中勾、悬停能力卡、键盘导航与点击提交**与常规列表完全一致**。
- 搜索期间左栏降饱和表示「当前为搜索结果」，点任一提供商行 → 清空查询并回到该提供商。
- 计数文案：`命中 N / 共 M 个模型`；无命中沿用原空态文案。

**理由**：用户的核心痛点就是「几十个模型上下滑动找不到」，跨提供商搜索才是这个痛点的直接解法；按 provider 过滤会把「知道模型名但不知道在哪个提供商」的检索变成不可能。

## 11. 修订 v1.2（2026-10-23 第二轮用户反馈）

### 11.1 能力卡补齐「设置页同款」字段（用户要求：照着设置页加）
设置页（@deepseek-ai/dsh-client-ui-settings-models）对模型的声明是：
- **输入类型** = inputModalities 数组（text / image），**至少保留一个**（最后一个勾选 disabled），取消 image 时**同时删除** imagePixelBudget / imageMaxBytes。
- **推理等级** = reasoningEfforts 对象（档位 → API 参数值）；off 的值只能是 null（表示不发该字段），其余必须非空字符串；**至少要有一个非 off 档**；默认档位 off/low/medium/high，默认参数值 = 档位同名。
卡片要与它对齐：
- 新增 **输入类型** 行：☑文本 ☑图片（最后一个勾选 disabled）。
- 新增 **推理等级** 行：折叠态显示档位概览 + 展开箭头；展开后每行 = [档位▾] [API 参数值] [删除]，底部 ＋添加档位。
- 会话级 **思考档位**（当前会话用哪个档）保留，与「推理等级的声明」是两件事，UI 上必须能区分。

### 11.2 面板尺寸收紧
弹窗宽从 min(720px,92vw) 收到 **min(600px, 90vw)**；左栏 **168px**（窄窗 150px）。

### 11.3 能力卡跟随鼠标
不再固定「面板上边缘之外」。卡片出现位置 = **鼠标当前位置的右侧**（left = pointer.x + 16），垂直与指针对齐；
越界时：右侧放不下 → 翻到指针左侧；上下越界 → 夹到视口内（≥12px）。**进入模型行时按该刻指针坐标定位一次，之后钉住**；行内移动指针不重定位；仅换行 / 视口尺寸变化 / 卡片实测高度变化时重算（scroll 不重算）。

### 11.4 搜索优先级
全局搜索不变，但**当前提供商的命中排在最前**（单独一组，标题带「当前」标记），其余按 orderProviderIds 依次分组。

### 11.5 左栏底部新增「全部提供商」
左栏最底部（现有「另有 N 个未配置的提供商」之下）新增一个 全部提供商 条目：点击后右栏切换为**按提供商分组的全量视图**（每个提供商一个组头 + 名下全部模型，含无凭证的只读行）。再点一次或点任一提供商回到单选视图。

## 12. 修订 v1.3（2026-10-23 用户实测反馈：卡片要钉住）

§11.3 的「跟随鼠标」**作废**。原因（用户原话）：「你得定住那个界面啊，不然鼠标一直放不上去」—— 跟随会让指针永远够不到卡片。

最终行为：
- **出现时定位**：在行 mouseenter 那一刻，按该时刻的指针坐标算一次位置（left = pointer.x + 16、top = pointer.y − 8；右侧放不下翻左、上下越界夹到 ≥12）；
- **然后钉住**：同一行内移动指针**不再重定位**（不做 rAF 跟随）；
- 指针移入卡片 → 卡片不动、保持打开、控件可操作；
- 只有**切换到另一行**或关闭后重开才按新的指针坐标重新定位。

验收：行内移动指针后卡片矩形的 left/top/width/height **逐字段不变**。
